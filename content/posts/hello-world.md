## 开篇

欢迎来到我的博客。这是一个基于 **Hugo + GitHub Pages** 搭建的免费、稳定、长期运行的中文博客。

## 技术栈

- **静态生成器**：Hugo（编译快、主题丰富）
- **托管**：GitHub Pages（微软大厂、免费、稳定运行超10年）
- **部署**：GitHub Actions（推送即自动构建发布）
- **图床**：私有 GitHub 仓库 + PicGo（免费、自动上传）
- **评论**：Giscus（基于 GitHub Discussions，直接显示在文章下方）
- **分发**：RSS 为主 + 半自动复制

## 写作体验

每周更新一篇文章，图片不多。在手机上用 Markdown 写完，直接 `git push`，几秒钟后文章就自动发布到网站。

> 图片粘贴时由 PicGo 自动上传到图床并返回链接，完全不用手动管理。

## 小结

这套方案的核心优势：**零依赖付费服务、数据自持、静态优先**，从根本上杜绝了"平台关停"和"服务过期"的风险，真正能做到稳定运行十年以上。
